# 解析流程

解析器面向正常公开分享链接，沿用原有已使用流程，并在每次请求和跳转前验证 HTTPS 主机名。

1. 请求分享页，从页面标题/文件名区域和大小区域提取文件信息。
2. 优先识别移动页的 `urlpt` 与 `link`；否则跟随 iframe，读取 `wp_sign`、`ajaxdata` 与 `ajaxm.php` 路径。
3. 按 `downprocess` 表单协议提交签名参数，读取响应的 `dom` 与 `url`，拼出中间下载地址。
4. 手动处理最终下载跳转；遇到 `acw_sc__v2` 页面时，以固定位置表与掩码计算 cookie 后重试。
5. 跳转最多 8 次，每个请求超时为 15 秒。分享页主机限定为 Lanzou HTTPS 域名，下载流程额外允许 `lanosso.com` 及其子域名。

页面标记或蓝奏云接口变更时，解析可能失效。最终下载域名 `lanosso.com` 在部分网络环境可能存在 DNS 解析问题。
